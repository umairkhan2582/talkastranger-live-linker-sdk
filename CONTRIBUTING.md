# Contributing to TalkAStranger Live Linker SDK

We welcome contributions from creators and developers worldwide!

## How to Contribute
1. Fork the repository.
2. Create your feature branch: `git checkout -b feat/my-new-feature`.
3. Commit your changes: `git commit -m 'feat: add support for platform XYZ'`.
4. Push to the branch: `git push origin feat/my-new-feature`.
5. Open a Pull Request!

## Good First Issues
- Adding new streaming platform adapters (e.g., Kick.com, Twitch, Trovo, Bigo).
- Adding integration examples for Next.js, React, or Electron.
- Enhancing documentation and streamer monetization tutorials.
